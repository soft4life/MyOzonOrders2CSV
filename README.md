# OzonMyOrders2csv

Расширение Chrome для выгрузки истории заказов покупателя Ozon в CSV для Excel. Текущая версия — **0.8.22**.

## Возможности

- Выгрузка выбранного периода, полного года или конкретного заказа по номеру/ссылке.
- Отдельная строка на товар: количество, цена, реальная цена, сумма позиции и заказа.
- Проверка возвратов; возможность включить товары с заявкой на возврат.
- Кэш закрытых заказов. Если «Использовать кэш» выключено, выбранный период перечитывается с Ozon, а записи других периодов сохраняются.
- Наблюдаемый режим обработки вкладок, остановка с сохранением частичного CSV и отчёта.
- Сохранение CSV и JSON через «Сохранить как» с проверкой завершения загрузки.

## Установка и обновление

1. Скачайте архив расширения из [последнего релиза](https://github.com/soft4life/MyOzonOrders2CSV/releases/latest) и распакуйте в постоянную папку `OzonMyOrders2csv`.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
4. При обновлении замените файлы в этой папке, нажмите «Обновить» у расширения и перезагрузите страницу Ozon.

## Использование

Откройте раздел заказов в своём аккаунте Ozon. В окне расширения задайте даты или выберите «Период → Год» и год. Для одного заказа укажите его номер либо ссылку. Нажмите «Выгрузить в CSV», дождитесь обработки и выберите папку сохранения.

CSV использует UTF-8 и разделитель `;`. Отменённые товары исключаются. Подробные правила цен, возвратов и кэша приведены в [README.txt](README.txt).

## Изменения 0.8.14–0.8.22

- Проверка фактического завершения скачивания; отображение отмены и ошибок сохранения.
- Изоляция строк итогов: бесплатная доставка больше не заимствует сумму товаров из соседней строки. Кэш переведён на схему v4.
- Предустановка полного календарного года с сохранением дат.
- Проверка подтверждённой даты перед обновлением записи кэша: другие периоды не изменяются.

## Данные и ограничения

Данные обрабатываются локально, расширение не отправляет историю заказов на сторонние серверы и не требует ключей API. Разметка Ozon может меняться. Автоматические проверки не заменяют проверку результата на реальном заказе; изменения этой версии на живом сайте пока не проверены.

## Загрузка истории

Числового ограничения прокруток нет. Автозагрузка продолжается до границы периода по датам получения в списке, конца списка или ручной остановки. Дата заказа для фильтрации берётся со страницы заказа. Без даты «от» история загружается до конца списка.

Цена распознаётся с группами тысяч: число из названия продавца не присоединяется к сумме. Подозрительная запись кэша с ценой товара выше итога перечитывается с Ozon; остальные записи сохраняются.

Граница рекомендаций распознаётся по отдельным текстовым блокам, а не только HTML-заголовкам. Для ранее выгруженных заказов с лишними товарами выполните выгрузку без использования кэша.

Наличие рекомендаций на странице списка не останавливает загрузку истории. Остановка списка определяется датами, прекращением прокрутки или кнопкой «Стоп». Фильтрация рекомендаций внутри отдельного заказа сохраняется.

История прокручивается с перекрытием экранов и паузой 2 секунды. Конец списка подтверждается шестью проверками без изменения позиции, высоты страницы и числа найденных заказов. Во время ожидания доступна кнопка «Стоп».
