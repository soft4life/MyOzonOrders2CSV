OzonMyOrders2csv
Версия 0.8.10

Номер установленной версии отображается в заголовке окна расширения.

Дата «до» при открытии окна автоматически устанавливается на сегодняшний день.
Если дата «от» позже даты «до», запуск блокируется с понятным сообщением.
После изменения даты «от» и «до» сохраняются и восстанавливаются при следующем
открытии окна расширения. Сегодняшняя дата используется только до первого сохранения.

Страница каждого заказа прокручивается до раздела рекомендаций, чтобы Ozon
успел подгрузить весь состав заказа. Каждый товар записывается в отдельную
строку CSV с теми же датой и номером заказа. Рекомендации не выгружаются.

Для тестирования можно ограничить загрузку истории полем
«Максимум прокруток». Значение по умолчанию — 100; 1–3 подходит только для
короткой проверки и может не дойти до нижней даты диапазона.
Расширение может завершить прокрутку раньше, если новые заказы перестали появляться.
Перед ограниченной загрузкой страница возвращается наверх. Расширение собирает
только карточки около текущего экрана на каждом шаге, поэтому заказы, оставшиеся
в DOM после прежней глубокой прокрутки, не увеличивают тестовую выборку.

Ozon может располагать заказы разных дат вперемешку. Поэтому расширение
проверяет все неотменённые карточки, загруженные выбранным числом прокруток,
а затем оставляет только подтверждённые даты из заданного периода.
Заказы без подтверждённой даты не попадают в итоговый CSV.
Если лимит закончился раньше нижней даты диапазона, расширение сообщает об этом
после выгрузки. Для полной проверки большого периода установите значение 100.
Лимит относится только к прокрутке общего списка заказов. Страница каждого
открытого заказа всегда прокручивается до конца товарного блока.

Для ускорения загрузки расширение использует даты получения в видимых карточках
как навигационный признак. Когда два экрана подряд содержат только даты получения
раньше даты «от», дальнейшая прокрутка прекращается. Дата заказа в CSV при этом
по-прежнему берётся со страницы конкретного заказа, а не подменяется датой получения.

УСТАНОВКА

1. Распакуйте ZIP в постоянную папку.
2. Откройте в Chrome: chrome://extensions
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку OzonMyOrders2csv.
6. Если Ozon уже был открыт, обновите вкладку один раз.

ИСПОЛЬЗОВАНИЕ

1. Войдите в обычный пользовательский аккаунт Ozon.
2. Откройте раздел «Заказы» (адрес содержит /my/order...).
3. Нажмите значок расширения.
4. При необходимости укажите период.
5. Нажмите «Выгрузить в CSV».
6. Не закрывайте вкладку Ozon, пока индикатор на странице не сообщит о завершении.
   В области прогресса это предупреждение показывается постоянно. При попытке
   закрыть или обновить основную вкладку браузер дополнительно запросит подтверждение.

ОСТАНОВКА

Нажмите «Стоп» в окне расширения или на индикаторе в правом нижнем углу
страницы Ozon. После остановки расширение предложит скачать частичный CSV и
диагностический отчёт JSON либо завершить без файлов. В отчёт записываются
версия, настройки запуска, этап остановки, количество полученных строк и
ошибки открытия или разбора заказов. CSV и JSON можно передать для анализа.
После завершения кнопка «Стоп» меняется на «Выйти».
После последнего заказа расширение распознаёт блок рекомендаций и завершает
автопрокрутку. Изменение высоты блока рекомендаций не продолжает выгрузку.

После загрузки списка расширение открывает каждый подходящий заказ в неактивной
вкладке, ждёт полной отрисовки товаров, считывает данные и закрывает вкладку.
Одновременно открываются не более двух заказов. Это может занять несколько
минут при большой истории. Ход работы показан в правом нижнем углу страницы.

Параметр «Показывать вкладки при обработке» включает наблюдаемый режим. В нём
страницы заказа и возврата открываются активными по одной, после проверки вкладка
закрывается, а браузер возвращается к списку заказов. При выключенном параметре
сохраняется быстрый режим с двумя неактивными вкладками. Выбранный режим
запоминается. При наблюдении окно расширения закрывается автоматически из-за
переключения активной вкладки; остановить процесс можно после возврата на вкладку
списка заказов или кнопкой «Стоп» на её индикаторе.

Товарные позиции распознаются двумя способами: по данным заказа и по видимому
блоку «название + цена + количество». Наличие отдельной ссылки на товар
необязательно.

CSV создаётся в кодировке UTF-8 с разделителем «;» и открывается в Excel.
Одна строка соответствует одному товару. Если товарные позиции на карточке
заказа скрыты, расширение создаёт строку на заказ с доступными данными.
Статус определяется отдельно для каждого блока доставки внутри заказа.
Товары из блоков «Отменён», «Возврат» и «Не выкуплен» в CSV не включаются,
а полученные товары из того же заказа сохраняются.

Для каждого подходящего заказа расширение также находит элемент «Вернуть товары»
и в той же фоновой вкладке открывает страницу выбора товаров для возврата. Позиции
с отметкой «Уже есть заявка на возврат» исключаются из CSV. Расширение работает
на этой странице только в режиме чтения: не устанавливает галочки, не нажимает
«Продолжить» и не создаёт заявку. Если страницу возврата не удалось прочитать или
товар нельзя уверенно сопоставить, товар остаётся в CSV, а проблема записывается
в диагностический отчёт.

В настройках есть галочка «Включать товары с заявкой на возврат». По умолчанию
такие позиции исключаются. Если галочка включена, они остаются в CSV со статусом
«Есть заявка на возврат» или «Частичный возврат» и могут быть отфильтрованы позже.

В CSV добавлена колонка «Статус возврата». Для сохранённых позиций она показывает
«Заявки на возврат нет», «Кнопка возврата недоступна», «Возврат для товара
недоступен», «Ошибка проверки возврата» или
«Найдена заявка — сопоставление не удалось». Уверенно распознанные позиции с
заявкой по-прежнему полностью исключаются из CSV.

Количество товара определяется только по явному полю количества или записи вида
«3 × цена». Числа «4 шт.» и «20 шт.» внутри названия упаковки больше не считаются
количеством купленных единиц.

Если Ozon показывает строку «110,20 ₽ 2 × 55,10 ₽», расширение записывает
количество 2 и цену одной единицы 55,10 ₽, а не сумму строки 110,20 ₽.

Колонка «Реальная цена» восстанавливает стоимость одной единицы до списания
баллов Ozon и включает распределённую долю доставки. Сначала рассчитывается
полная стоимость заказа «Товары + Доставка», затем она распределяется между
всеми товарными единицами пропорционально отображаемым ценам. Поэтому сумма
«Реальная цена × Количество» по заказу соответствует товарам вместе с доставкой
(с возможным расхождением в копейку из-за округления цены единицы).

Денежные значения в CSV используют десятичную запятую, чтобы Excel не превращал
цены с точкой в даты. Имя файла содержит обе границы выбранного периода, время и
версию в конце, например ozon_orders_2026-08-01_2026-09-13_14-25-30 (v0.8.10).csv.
Индикатор обработки показывает
«проверено 8 из 100».

Перед заголовками таблицы CSV содержит блок параметров: версия приложения, время формирования,
диапазон, режим вкладок, лимит прокруток, настройка возвратов, количество заказов
и строк, количество возвращённых товарных единиц, а также причина завершения
загрузки списка с рекомендацией пользователю.

КЭШ ЗАКРЫТЫХ ЗАКАЗОВ

Расширение сохраняет в локальном хранилище Chrome полностью разобранные закрытые
заказы. Кэшируется заказ, если для всех его товарных позиций срок возврата истёк,
товар нельзя вернуть либо все позиции уже возвращены/имеют заявку на возврат.
Частично закрытые заказы и заказы с действующим сроком возврата не кэшируются.

При повторной выгрузке товары, количество, цены, суммы и возвратные статусы такого
заказа берутся из кэша. Страницы заказа и возврата повторно не открываются.
В прогрессе показывается пометка «из кэша», а в параметрах CSV — число заказов,
взятых из кэша и впервые сохранённых в него. Кэш хранится только в текущем профиле
Chrome и удаляется вместе с данными расширения или при удалении расширения.
Чтобы сохранять накопленный кэш между версиями, распаковывайте обновление поверх
той же папки и нажимайте кнопку обновления расширения, не удаляя его из Chrome.

В окне расширения показывается число заказов и товарных позиций в кэше. Кнопка
«Скачать JSON» создаёт читаемую копию кэша, которую можно открыть Блокнотом и
передать для диагностики. Кнопка «Очистить» удаляет только кэш после подтверждения;
даты и остальные настройки сохраняются.

Галочка «Использовать кэш» включена по умолчанию. Если её снять, расширение
игнорирует сохранённые данные, заново открывает и разбирает заказы на Ozon, а
после успешной проверки обновляет кэш новыми данными.

ИНТЕРФЕЙС

Параметры периода и прокрутки находятся в левой колонке «Параметры выгрузки».
Настройки возвратов, режима вкладок и кэша находятся в правой колонке «Настройки».
Компактная двухколоночная форма помещается в окне расширения без прокрутки.

В версии 0.8.9 схема кэша обновлена до v2. Закрытые заказы, ранее сохранённые
с ошибочным количеством 1, перечитываются с Ozon. Количество определяется по
записи «2 × 55,10 ₽» и резервно по отношению суммы позиции к цене единицы.

В версии 0.8.10 модуль переименован в OzonMyOrders2csv.

Отдельные колонки «Год» и «Месяц» формируются из даты заказа для фильтрации.
«Сумма заказа» рассчитывается как «Товары + Доставка». Строка «Оплачено» не
используется как итог, потому что она уже уменьшена на списанные баллы Ozon.
Если рядом с доставкой нет денежной суммы («Входит в заказ»), доставка считается
бесплатной.

Если строки «Оплата баллами Ozon» нет и доставка бесплатная, «Реальная цена»
совпадает с ценой товара без пропорционального изменения.

КОНФИДЕНЦИАЛЬНОСТЬ

Расширение работает только на ozon.ru. Оно не запрашивает логин, пароль или
ключи API и не отправляет собранные данные на сервер. CSV создаётся локально
в браузере.

ОГРАНИЧЕНИЯ

Ozon может менять разметку личного кабинета. Если заказы перестали
распознаваться, расширение нужно обновить под новую структуру страницы.
